# Projet Swift : Gestion d'une bibliothèque (CHCL)

Cours de Programmation orientée objet, Université d'État d'Haïti (Campus Henry Christophe de Limonade).

## Lancer le projet
```
swift run
```
Le menu propose l'option 8 qui exécute automatiquement les tests demandés dans le sujet.

## Lancer les tests unitaires
```
swift test
```

## Fichiers
- `Livre.swift`, `LivrePapier.swift`, `LivreNumerique.swift` : les livres (héritage)
- `Adherent.swift` : l'adhérent (3 livres maximum)
- `Bibliotheque.swift` : le catalogue
- `main.swift` : le menu et les tests du sujet
