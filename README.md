# Projet Swift : Gestion d'une bibliothèque (CHCL)

Projet réalisé dans le cadre du cours de Programmation orientée objet à l'Université d'État d'Haïti (Campus Henry Christophe de Limonade).

**Membres du groupe :**
1. Lorvenski ALCIMÉ
2. Louis Marie Olivier ROLLES
3. Mike Sevy JOSEPH

## Lancer le projet

Pour exécuter le projet, utilisez la commande suivante dans le terminal :

`swift run`


## Dossier `document_attache`

Ce dossier contient :
- Le diagramme UML du projet.
- Le document PDF présentant les tests réalisés.

## Consultation du document PDF

Le document PDF est disponible dans le dossier `document_attache/test_swift`.

Pour le consulter, ouvrez le fichier avec un navigateur Web (Chrome, Edge ou Firefox) ou un lecteur PDF.

## Fichiers principaux

- `Livre.swift`, `LivrePapier.swift`, `LivreNumerique.swift` : gestion des livres et de leur héritage.
- `Adherent.swift` : gestion des adhérents (3 livres maximum).
- `Bibliotheque.swift` : gestion du catalogue de la bibliothèque.
- `main.swift` : menu principal du programme.
